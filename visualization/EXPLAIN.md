# Sensitivity Analysis Results Explanation

This document explains the four visualizations generated by the CPT sensitivity analysis for the **P05-CPT-SENSITIVITY** scenario.

---

## 📋 Scenario Context

**Scenario**: `P05-CPT-SENSITIVITY`  
**Evidence**: `AssignmentCompletion = Medium`, `ExamDifficulty = Medium`  
**Query**: `Performance` (states: Fail, Pass, Distinction)

### Baseline Posterior Distribution

| Performance | Probability |
| ----------- | ----------- |
| Fail        | 0.2500      |
| Pass        | 0.5500      |
| Distinction | 0.2000      |

This baseline comes from the CPT row: `Performance | Medium|Medium = [0.25, 0.55, 0.20]`

---

## 📊 Visualization 1: KL Divergence Bar Chart

**File**: `sensitivity_kl_divergence.png`

### What it shows

Kullback-Leibler divergence D_KL(Baseline || Modified) for each CPT modification.

### Results

```
Direct Modifications (Performance CPT):
├── Shift 0.1 Pass → Distinction:     KL = 0.0293
├── Shift 0.1 Fail → Pass:            KL = 0.0358
└── Reduce Fail/Pass 50%, boost Dist: KL = 0.3348

Indirect Modifications (Upstream CPTs):
├── StudyConsistency | High|High:     KL ≈ 0.0000
└── AssignmentCompletion | Medium:    KL ≈ 0.0000
```

### Interpretation

- **KL divergence measures information loss** when using the modified distribution to approximate the baseline
- **Direct modifications** (changing Performance CPT) produce **significant KL divergence** (0.03–0.33)
- **Indirect modifications** produce **near-zero KL divergence** — the posterior doesn't change at all
- **Largest KL (0.3348)**: The extreme modification reducing Fail/Pass by 50% and boosting Distinction to 0.60

## 🧠 Theoretical Explanation: Why Indirect Changes Have Zero Effect

### The Network Structure

```
PriorPreparation → StudyConsistency → AssignmentCompletion → Performance
Attendance ─────────────────────────────┘                    ↑
ExamDifficulty ──────────────────────────────────────────────┘
```

### D-Separation Principle

When we observe **AssignmentCompletion = Medium** and **ExamDifficulty = Medium**:

- These are the **direct parents (Markov blanket)** of Performance
- Performance becomes **conditionally independent** of all upstream variables
- The CPT row `Performance | Medium|Medium` **fully determines** the posterior

### Mathematical Proof

```
P(Performance | AssignmentCompletion=Medium, ExamDifficulty=Medium,
    StudyConsistency, PriorPreparation, Attendance)
= P(Performance | AssignmentCompletion=Medium, ExamDifficulty=Medium)
= CPT[Performance][Medium|Medium]
```

The upstream CPTs (StudyConsistency, PriorPreparation, Attendance) only affect Performance **through** AssignmentCompletion. Once AssignmentCompletion is observed, that pathway is "blocked."

---

## 🎯 Conclusions for the Midterm

### 1. **Model Sensitivity is Localized**

The posterior over Performance is **highly sensitive** to its own CPT parameters but **completely insensitive** to upstream CPTs when direct parents are observed.

### 2. **Practical Implication**

- If you have data on `AssignmentCompletion` and `ExamDifficulty`, you **don't need accurate CPTs** for StudyConsistency, PriorPreparation, or Attendance to predict Performance
- Effort should focus on **calibrating the Performance CPT** and measuring AssignmentCompletion/ExamDifficulty

### 3. **Experimental Design Insight**

To test upstream CPT sensitivity, you must **NOT observe the direct parents**. Try scenario `P05-LITTLE-EVIDENCE` (only Attendance observed) — there, upstream changes WILL propagate to Performance.
